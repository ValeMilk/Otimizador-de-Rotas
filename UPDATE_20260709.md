## 🐛 Bug CRÍTICO Corrigido: Tempo de Deslocamento Não Era Contabilizado

### O Problema Original
A documentação anterior ("UPDATE_20260708.md") descrevia uma solução fundamentalmente errada:
- ❌ Usava buffer para verificação de feasibility
- ❌ Não contabilizava tempo de deslocamento em `tempoUsado`
- ❌ Violava regra de negócio crítica

**Regra de Negócio (Declaração do Cliente)**:
> "O funcionário cumpre carga horária na rua, logo o trânsito FAZ PARTE da jornada de 8 horas"

**Tradução Técnica**:
- Tempo Total = Visitação + Deslocamento (AMBOS)
- Limite: ≤ 480 minutos (8h Mon-Fri) ou ≤ 240 min (4h Saturday)
- Sem exceções, sem overflow permitido

### Root Cause Analysis
Em `utils/dynamicRouteGenerator.ts`, função `tentarAlocarEmDia()` (linhas 407-467):

**❌ ERRADO (Anterior)**:
```typescript
// Contabilizava APENAS tempo de visitação
agenda[dia].tempoUsado += tempoVisita;  // ❌ Deslocamento não era contado!
```

**✅ CORRETO (Novo)**:
```typescript
// Contabiliza AMBOS: visitação + deslocamento real
const tempoTotalNecessario = tempoVisita + tempoDeslocamentoReal;
agenda[dia].tempoUsado += tempoTotalNecessario;  // ✅ OBRIGATÓRIO
```

### Impacto Técnico do Bug
- Routes poderiam ultrapassar 8 horas ao somar visitação + deslocamento
- Exemplo: Visitação 7h45m + Deslocamento 1h = 8h45m ❌ (overflow!)
- Alocação violava capacidade legal diária

## ✅ Solução Implementada: Contabilização Correta

### Algoritmo Correto (v4.2.2)

**Função: `tentarAlocarEmDia()` (linhas 407-467)**

```typescript
function tentarAlocarEmDia(
  clienteExpandido: ClienteExpandido,
  dia: number,
  agenda: AgendaSemanalInterna,
  matrizTempos: MatrizTempos  // ← NOVO PARÂMETRO
): boolean {
  const cliente = clienteExpandido.cliente;

  // 1. Validações básicas
  if (!podeVisitarNoDia(clienteExpandido, dia, cliente)) {
    return false;
  }

  // 2. CALCULA TEMPO DE DESLOCAMENTO REALISTA
  let tempoDeslocamentoReal = 0;
  const visitasNoDia = agenda[dia].visitas;

  if (visitasNoDia.length === 0) {
    // Primeiro cliente: estimativa conservadora
    tempoDeslocamentoReal = 8;  // minutos
  } else {
    // Clientes subsequentes: usa matriz OSRM
    const ultimaVisita = visitasNoDia[visitasNoDia.length - 1];
    if (matrizTempos && matrizTempos[ultimaVisita.clienteId]?.[cliente.id]) {
      tempoDeslocamentoReal = matrizTempos[ultimaVisita.clienteId][cliente.id];
    } else {
      // Fallback: Haversine + 1.5x
      tempoDeslocamentoReal = calcularTempoFallback(...);
    }
  }

  // 3. TRAVA ABSOLUTA - Verificação matemática inflexível
  const tempoVisita = cliente.visitDurationMinutes;
  const tempoTotalNecessario = tempoVisita + tempoDeslocamentoReal;  // ← AMBOS!
  const capacidadeDisponivel = obterCapacidadeDisponivel(agenda, dia);

  if (tempoTotalNecessario > capacidadeDisponivel) {
    // Cliente NÃO CABE - REJEITA ABSOLUTAMENTE
    return false;
  }

  // 4. ALOCA E CONTABILIZA AMBOS OS TEMPOS
  clienteExpandido.visitasAlocadas.add(dia);
  agenda[dia].visitas.push({
    clienteId: cliente.id,
    clienteNome: cliente.name,
    latitude: cliente.latitude,
    longitude: cliente.longitude,
    duracao: cliente.visitDurationMinutes,
    frequency: cliente.frequency,
  });

  // ⚠️ CRÍTICO: ATUALIZA COM VISITAÇÃO + DESLOCAMENTO REAL
  // Garante que jornada total NUNCA ultrapassará 480 min (8h)
  agenda[dia].tempoUsado += tempoTotalNecessario;

  return true;
}
```

```typescript
function calcularDistanciaDeTempoMinutos(tempoMinutos: number): number {
  const velocidadeMedia = 40; // km/h
  const distanciaKm = (tempoMinutos / 60) * velocidadeMedia / 1.5;
  return Math.round(distanciaKm * 10) / 10; // One decimal place
}
```

**Lógica**:
- Usa inversa da fórmula de conversão distância → tempo
- Velocidade média: 40 km/h
- Multiplicador 1.5x: compensa desvios de rota vs. linha reta (Haversine)
- Resultado: 1 casa decimal (ex: 23.0 km)
